# Hyusk control deck

Mode: Operate. Scope: GNOME indicator and native GTK workflow editor.
The user's modular handheld-console reference pins the art direction. Existing
butterfly branding, native keyboard behavior, and real workflow data remain.

## Direction contract

THESIS: A compact instrument for running real routines, with a visible separation
between the agent's conversation and queued workflow execution.

OWN-WORLD: Graphite casing, native themed inset surfaces, blue transport keys,
amber timer modules, mint playback modules. The butterfly is the sole brand mark.
Use native type and clear text status; avoid fake hardware or invented telemetry.

STORY: Pick a routine from the library, inspect its ordered modules, edit with
native controls, and run it while retaining the current conversation.

FIRST VIEWPORT: A dark library rail with butterfly, search and workflow names;
a large editor with name/voice controls, an exposed ordered action sequence and
fixed feedback footer. Scheduling is expandable so it cannot crowd out steps.
The Shell companion has a small state display and searchable quick-run menu.

FORM: User-pinned modular handheld console, translated to native GNOME controls;
seed 10e83599 is subordinate to that supplied reference. Code-led implementation.
Signature interaction: real action numbers become colored module keys; clicking
a workflow shows queued/running/failure state without cancelling the agent.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

Outcome: native GTK finish approved after correcting selection, draft retention,
search behavior, and saved-before-run execution. See
`review/control-deck-verdict.md`. The final review PNG uses isolated illustrative
config/runtime data. Shell styling still needs a rendered check after login.

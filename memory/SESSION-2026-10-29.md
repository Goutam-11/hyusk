### A8 — explicit policy registry

`tools/safety.rs` now owns a `ToolName` enum (one variant per registered
tool), an exhaustive `policy()` match with no wildcard, a row per tool with an
allow decision or an argument classifier, and the model-facing guidance for
that row. `requires_approval` is `policy_for(name)` plus the row's rule;
unknown tool names and unparseable arguments still ask.

`main.rs` grew `ToolSetup` and `build_tools`, so tool registration lives in one
function that a test can walk:
`tool_policy_tests::every_registered_tool_has_an_explicit_policy`. Verified by
temporarily registering a probe tool: the test failed with
`tools registered without an approval policy: ["ghost"]`.

Because unknown names now ask, the text and Sonic paths check that the tool
exists before arming a confirmation; otherwise a hallucinated tool name would
publish a card for a call that can never run. That reordering was verified
against the old order: `unknown_tool_name_reports_a_missing_tool_instead_of_arming_an_approval`
fails when the existence check is moved back after the gate.

`browser` is recorded as `Decision::Allow` — today's effective behaviour — and

### A2 — free research, preflighted workspace

### What changed

- `reply.rs` gained `AFFIRMATIVES`, `NEGATIONS`, and `NEGATION_TOKENS` tables
  plus `normalized_decision_phrase`, which removes apostrophes before splitting
  so contractions classify instead of becoming "don t".

  sentences), denials (including "don't do that" spelled both ways), denial

  "stop listening" still ending the voice session.

### Decisions

- A denial anywhere in the utterance refuses the action, not only a leading
  one, because "yes, but not yet" must not run a stored call. The cost of a
  false refusal is one re-ask; the cost of a false approval is an unwanted
  action.
- A transcript with a question mark never approves, which covers "okay, but
  what does it do?" without guessing at model-side question detection.
- A courtesy phrase is an approval on its own ("okay") and not with a question
  attached - the acceptance criterion read literally.
- Sonic uses the same shared grammar, so it improved too; A7 still owns moving
  its decision off the raw transcript.

### Commit

`13d955d` `fix(agent): drop a pending action when the user changes the subject (A5)`

### What changed

### Decisions

  the tool result.
- A cancelled turn keeps the call armed. Dropping it would throw away a pending
  decision because of a barge-in the user never answered.

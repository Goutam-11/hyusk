### Code changes

- **D3 — wake defaults.** `WAKE_CLAP_ENABLED` and `WAKE_WORD_DENOISE` now
  default to `false` in normal startup and `WAKE_TEST`; the detector
  constructor default was aligned. Added `WAKE_WORD_STEP_MS` to the README
  configuration table. `.env.example` unchanged.
- **D2 — task approval.** Added a `task` arm to `tools::safety::requires_approval`
  so any `delegate` call (research or workspace) arms a one-shot confirmation.
  Added `approval_arguments`, which rewrites the stored call with the canonical
  workspace root; both the runner and Sonic approval paths use it. Added a
  regression test covering workspace, research, `list`, `cancel`, and root
  pinning.
- **D7 — pairing secret.** Removed the `pairing` action from the model-facing
  `mobile` schema and its execution arm; the indicators keep their direct path
  via `hyusk-pairing.json` and `pair_phone`.

### Workflow clarification

The earlier claim that D2 would break workflow task delegation was wrong:
workflow steps come from the deterministic `Action` enum in
`src/agent/commands.rs`, which has no task variant. The approval-gated step
error now names the tool and points at the assistant, the README states that
delegation is not a workflow step, and the existing regression test asserts the
tool name.
